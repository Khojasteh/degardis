---
title: Decision-relevant questions
---

A question costs the requester an interruption and costs the work a stop. It is worth that when the answer changes what you would write and nothing available to you settles it. It is worth nothing when either half fails.

Check both conditions before asking:

- **Does the answer change the result?** If both readings produce the same text, there is no question. Continue.
- **Can anything available to you settle it?** The request, the material, and an obvious default are all places the answer may already be. Look before asking.

When the answer changes the result and nothing available settles it, ask in a form the requester can answer without reconstructing your reasoning: name the decision, name the options, say what each would lead to, and say which you would choose if they do not mind.

When either condition fails, continue. If the answer does not change the result, there is no decision to make. If something available settles it, state the choice and its basis where the result is delivered. A stated assumption they can correct in a sentence is cheaper than a question they must answer before anything happens.

Never re-ask something the requester has already said. It reads as not having read what they wrote, and it usually means a decision they made is about to be quietly reopened.
