# Outline, then draft: worked examples

Optional explanation. Nothing here is required.

## A three-subject release note

The material covered pricing, availability, and a deprecation. The outline put
availability first because the reader's purpose was deciding whether to upgrade,
and the deprecation last because it qualified the upgrade rather than motivating
it.

## A single-subject incident report

One subject, so the outline was a sequence rather than a set of headings:
condition, trigger, effect, remedy.
